# Site simples da Reddiac

Projeto estático para hospedar no GitHub Pages.

## Estrutura

```text
index.html
assets/
  css/
    style.css
  img/
    logo-reddiac.svg
    favicon.svg
    pcb-hero.png
```

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub, por exemplo `reddiac-site`.
2. Envie todos os arquivos deste pacote para a raiz do repositório.
3. No GitHub, vá em **Settings > Pages**.
4. Em **Build and deployment**, selecione:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Salve e aguarde o GitHub gerar o link.
